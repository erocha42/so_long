### *Description*

<img src="https://flagcdn.com/16x12/gb.png" alt="GB Flag">

so_long is a small 2D game designed to help you work with textures, sprites, and basic gameplay elements using the MiniLibX library. The goal is to collect all items on the map and reach the exit with the minimum number of moves.

<img src="https://flagcdn.com/16x12/fr.png" alt="FR Flag">

so_long est un petit jeu en 2D conçu pour manipuler des textures, des sprites et des éléments de gameplay basiques avec la bibliothèque MiniLibX. Le but est de ramasser tous les objets de la carte et d'atteindre la sortie en un minimum de mouvements.

### *Instructions*

<img src="https://flagcdn.com/16x12/gb.png" alt="GB Flag">

Compile the project with `make`. To launch the game, run the executable `./so_long` followed by the path to a map file with a `.ber` extension. The map must be rectangular, enclosed by walls, and contain at least one exit, one collectible, and one starting position.

<img src="https://flagcdn.com/16x12/fr.png" alt="FR Flag">

Compilez le projet avec `make`. Pour lancer le jeu, exécutez `./so_long` suivi du chemin vers un fichier de carte avec l'extension `.ber`. La carte doit être rectangulaire, entourée de murs, et contenir au moins une sortie, un objet collectable et une position de départ.
